# Colorfly

Generador de paletas de colores aleatorias.

## Descripción

Colorfly es una aplicación web que permite generar paletas
de colores de manera aleatoria, elegir la cantidad de colores
y visualizar sus códigos en diferentes formatos.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript

## Funcionalidades principales

- Generación aleatoria de paletas.
- Selección de 6, 8 o 9 colores.
- Visualización de códigos HEX, HSL y RGBA.
- Interfaz sencilla e intuitiva.
